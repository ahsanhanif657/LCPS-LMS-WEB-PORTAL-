# Quick check before presenting

1. Apply the patch to the existing project and rebuild/start it.
2. Sign in as Teacher. Attendance should show Mark attendance and View attendance records. Choose the assigned class and save a test register in a test environment.
3. Sign in as HOD. Check marking for the HOD's own class and session/subject browsing under Department records.
4. Check a student account: subject attendance is readable; editing and marking actions are absent.
5. At phone width, check the menu open/close buttons, announcement bell, profile initials/photo and Sign out. Verify a long subject name wraps and all dashboard subject cards remain visible.
6. Open attendance: each student should have a mobile card, a colored status control and Late-only remarks. Wide reports/timetables should scroll inside their panel rather than widening the page.
7. Open Admin account editor and results. Fields should fit their dialog and mark-entry boxes should have visible borders.
8. Check delegated timetable incharge access with a real assigned user.

If attendance marking is denied, check the user's View attendance and Record / correct attendance permissions and active teaching assignment. The patch preserves intentional access restrictions.
